# ADR-002 - Papel do web_frontend

- Status: Aceito
- Data: 2026-08-10

## Decisão

`web_frontend` será site institucional + portal de Responsável do Supermercado + portal de Administrador.

O consumidor usa Android.

## Motivo

As tarefas de importação em lote, gestão de produtos, auditoria e administração são mais adequadas a uma interface web de maior densidade. Isso também elimina duas implementações concorrentes da experiência do consumidor.
